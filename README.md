1. Название: BookHouse — Online Library Management System.

2. Технологии: Django MVT, SQLite, CSS (Glassmorphism).

3. Как запустить:

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver

4. Функции: CRUD для книг, фильтрация по цене/автору/категории, статистика (aggregate/annotate), авторизация
